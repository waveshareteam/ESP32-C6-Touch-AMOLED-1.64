# 02_I2C_QMI8658

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Reads motion data from the QMI8658 IMU over I2C.

## 硬件需求

- ESP32-C6-Touch-AMOLED-1.64 开发板

## 怎么运行

1. 安装 Arduino-ESP32 3.2.0。
2. 选择 `ESP32C6 Dev Module`，Flash 设置为 16 MB。
3. 打开 `.ino` 文件并上传。

## 预期现象

示例启动后通过串口输出运行状态，并使用开发板上的对应硬件。
