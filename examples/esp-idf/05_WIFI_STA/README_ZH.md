# 05_WIFI_STA

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Connects to a configured Wi-Fi network and demonstrates station mode.

## 硬件需求

- ESP32-C6-Touch-AMOLED-1.64 开发板

## 怎么运行

```bash
idf.py set-target esp32c6 build flash monitor
```

## 预期现象

示例启动后通过串口输出运行状态，并使用开发板上的对应硬件。
