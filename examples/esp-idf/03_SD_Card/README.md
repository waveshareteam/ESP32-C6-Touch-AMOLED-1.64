# 03_SD_Card

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Initializes the SD card interface and demonstrates card access.

## Hardware Required

- ESP32-C6-Touch-AMOLED-1.64 development board

## How to Run

```bash
idf.py set-target esp32c6 build flash monitor
```

## Expected Result

The example starts and reports its status through the serial monitor while using the board hardware.

暂无。
